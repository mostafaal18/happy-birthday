# 🎂 Birthday Wish

یک صفحه‌ی تولد انیمیشنی با React + Vite

## ✨ امکانات
- افکت تایپ‌رایتر برای متن «تولدت مبارک»
- قلب‌های انیمیشنی با هر حرف
- بادکنک، کاغذرنگی و ستاره‌های چشمک‌زن
- پخش آهنگ پس‌زمینه
- دکمه پخش مجدد

## 🚀 اجرا

\`\`\`bash
npm install
npm run dev
\`\`\`

## 📦 ساخت نسخه production

\`\`\`bash
npm run build
\`\`\`

## 🎵 اضافه کردن آهنگ

فایل آهنگت رو با نام `music.mp3` توی پوشه `public/` بذار.

## 🛠️ تکنولوژی‌ها
- React 18
- Vite
- CSS Animations
